# Contributing

Thanks for helping PIPT learn.

For a small fix, open a focused pull request. For a new lesson, dependency, route, or change to PIPT's visual identity, open an issue first so the direction can be discussed before implementation.

Please keep changes consistent with the project's principles:

- preserve the restrained, minimal interface;
- make learning visible through behavior, not marketing copy;
- distinguish simulated behavior from autonomous execution;
- keep accessibility and reduced-motion support intact; and
- run `npm run lint` and `npm run build` before submitting.
