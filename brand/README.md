# Scaur brand assets

The Scaur identity uses a stepped rock-face mark, warm paper, and near-black ink.
The mark is intentionally wordless and geometric so it remains legible at small
sizes without suggesting a mascot, trading chart, or generic AI product.

## Files

| Asset | Use |
| --- | --- |
| `scaur-mark.svg` | Primary transparent vector mark |
| `scaur-mark.png` | 1024px transparent raster mark |
| `favicon.svg` | Browser icon on the paper background |
| `scaur-pfp.svg` / `.png` | Square profile image with circular-crop padding |
| `scaur-banner.svg` / `.png` | 1500×500 social header without a repeated mark |

## Colors

- Paper: `#EDE9DC`
- Ink: `#2A2620`
- Muted text: `#6F6A60`
- Rule: `#C8C1B2`
- Link: `#1648B5`

Preserve the mark's proportions and keep clear space around it. Do not add glow,
gradients, shadows, circuitry, or financial-chart decoration.
