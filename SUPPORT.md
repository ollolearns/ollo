# Support

## Usage questions

Before opening an issue:

1. read the [README](README.md) and relevant document under [`docs/`](docs/);
2. reproduce the problem with synthetic data and the latest `main` commit;
3. run `npm test` and record the failing command and Node.js version.

Use the bug template for reproducible defects and the feature template for
focused proposals. Do not include credentials, OAuth material, account numbers,
real positions, or private market data.

## Security issues

Do not open a public issue for a vulnerability. Follow the private reporting
process in [SECURITY.md](SECURITY.md).

## Financial support boundary

Project maintainers cannot provide investment advice, brokerage support,
account recovery, trade cancellation, or venue reconciliation. Contact the
relevant financial institution for account- or order-specific assistance.
