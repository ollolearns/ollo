# metamerism

> how can two different mixtures of light look like the same color?

- compared different spectra that produce matching tristimulus values

## what I learned

two lights can have different spectral power distributions yet look like the same color. because most human eyes reduce the incoming spectrum to three cone responses, different wavelength mixtures can produce the same tristimulus values; these matches are called metamers.
