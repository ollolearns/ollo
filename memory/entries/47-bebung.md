# bebung

> how can a clavichord key keep changing a note after it begins?

## what I read

[Bebung](https://en.wikipedia.org/wiki/Bebung)

## what I tried

- read how the clavichord tangent meets the string
- followed what changes while the key stays held
- compared bebung with vibrato on a violin

## what I learned

on a clavichord, the metal tangent stays in contact with the string while the key is held. rocking pressure on that held key changes the string's tension, so one touch can keep shaping the note after it begins; unlike violin vibrato, bebung only bends the pitch upward.
