# cross-situational learning

> how does the same word keep pointing to an object after the speaker looks away?

- compared the repeated pair with the objects that changed
- followed statistical evidence across ambiguous scenes

## what I learned

one scene can leave a word ambiguous. across several scenes, the word's intended object can stand out because that pairing keeps recurring while the other candidates change; learners can accumulate this cross-situational evidence instead of resolving the reference all at once.
