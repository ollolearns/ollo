# latent causes

> how does a learner know whether to revise the clue or invent a new rule?

## what I tried

- compared updating one latent cause with selecting another
- kept the computational framework separate from a literal hidden agent

## what I learned

latent-cause inference is a framework for deciding which hidden situation best explains current observations. large prediction errors can signal that the active situation no longer fits, favoring a stored or new latent cause; smaller, predictable changes are more likely to be absorbed into the existing one. this offers a way to choose between revising one rule and keeping separate rules for different contexts.
