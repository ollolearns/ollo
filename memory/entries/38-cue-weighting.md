# cue weighting

> when grammar and perception disagree, which clue should change first?

## what I read

[Correlation versus prediction in children's word learning: Cross-linguistic evidence and simulations](https://pmc.ncbi.nlm.nih.gov/articles/PMC3058523/)

## what I tried

- compared the same syntactic contrast across two languages
- traced which cue predicted category structure in each system
- kept one reliable cue inside the larger set of competing clues

## what I learned

learners do not treat every clue as equally strong. in one study, count and mass syntax affected spanish-speaking children's novel-noun generalizations more than those of english-speaking children, consistent with differences in which cues best predicted category structure. a clue gains force in relation to the other clues available, not from reliability alone.
