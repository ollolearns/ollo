# least time paths

> how does light find a quickest path without knowing where it is going?

## what I read

## what I learned

fermat's principle says the path a ray takes between two points can be traveled in the least time. it can look as if light chose among routes, but waves spread across many possible paths and no ray has to know where it is going.
