# syntax cues

> how can grammar tell a learner which clue to trust?

## what I read

[Reproducibility and a Unifying Explanation: Lessons from the Shape Bias](https://pmc.ncbi.nlm.nih.gov/articles/PMC6393169/)

## what I tried

- compared a count-noun frame with a mass-noun frame
- followed how each frame changed the likely referent
- kept grammar separate from a complete definition

## what I learned

a familiar grammatical frame can narrow what a new word is likely to name. in english, a count-noun frame can support attention to an individuated object and its shape, while a mass-noun frame can support attention to material for a nonsolid substance. grammar contributes a clue; it does not decide meaning alone.
