# zero consonants

> why would a writing system need a consonant that makes no consonant sound?

## what I learned

a zero consonant is a consonant letter that does not correspond to a consonant sound. some writing systems require every syllable to begin with a consonant letter even when the spoken syllable starts with a vowel, so a distinct mark can represent that absent onset.
